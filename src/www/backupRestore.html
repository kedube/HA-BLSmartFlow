Backup & Restore

Backup
The file contains your Wi-Fi password, printer access code, and the Home Assistant and login passwords in plain text, so keep it somewhere private. Downloading needs a Web Page Login, set in Settings.

Restore
Restoring replaces every setting, including Wi-Fi, and restarts the controller. If the file's Wi-Fi settings don't work here, the controller opens its BLSmartFlow setup network so you can correct them.
